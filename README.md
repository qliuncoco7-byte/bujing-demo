# 补镜 · 剪辑器内的辅助画面检索与生成 Demo

一个纯前端交互 Demo：在简化剪辑工作区里，为 4 秒待补画面输入需求，可选参考前后镜头，比较素材库候选或生成候选，先做上下文预览，再插入、替换或撤销。

- **Demo**：https://qliuncoco7-byte.github.io/bujing-demo/
- **操作录屏**：https://qliuncoco7-byte.github.io/bujing-demo/deliverables/bujing-demo.mp4（约 2 分 07 秒，含系统 TTS 旁白；本地同文件 `public/deliverables/bujing-demo.mp4`）
- **产品说明 PDF**：https://qliuncoco7-byte.github.io/bujing-demo/deliverables/bujing-product-notes.pdf（5 页，内部稿；第 4 页待本人补充）
- **源码仓库**：https://github.com/qliuncoco7-byte/bujing-demo
- **说明源文件**：`docs/产品说明.html`
- **AI 使用记录**：`docs/ai-usage-record.md`

## 本地运行

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 生产构建到 dist/
npm run preview    # 预览生产构建
```

构建使用相对路径（`base: './'`），可部署在域名根路径或子路径。没有后台、账户、数据库或 API Key。

## 演示路径

1. 打开预设项目「城市里的树」，点击时间线上 5–9 秒的「待补画面」区间。
2. 点击「补充空镜」，输入（或填入示例）「风吹树冠，不要人物。」。
3. 可选开启「参考原片匹配」，查看并修改摘要：科普讲解 · 漫画表现 · 轻松；参考范围是前后相邻镜头。
4. 在「素材库」比较 3 条示例候选：
   - 实拍观感、强风：对象匹配，但表现形式与运动不匹配；
   - 漫画、强风：形式匹配，风力过强；
   - 漫画、微风：与当前条件相符。
5. 任选候选「单独预览」，或「放入片段预览」播放前镜头 → 候选 → 后镜头；确认后插入。
6. 插入后主预览与时间线同步变化，口播保持连续；可撤销或替换。
7. 切到「AI 生成」，点击生成（预制结果），再用「树摆动太剧烈，改成微风，其他保持」修改一次。
8. 「演示控制」可让下一次生成失败，失败后条件保留，可重试或改用素材库。
9. 顶栏「重置示例」恢复完整初始状态。

键盘：`Space` 播放/暂停，`⌘Z / Ctrl+Z` 撤销插入，`Esc` 关闭面板/预览/弹窗。

## 模拟范围与素材说明

- **这是交互 Demo**：原片解析、检索与生成均为预制示例，不调用任何模型或素材 API，不上传原片，不含登录、支付、后台、素材社区或完整剪辑功能。
- **画面**：全部由本项目用 Canvas 程序动画制作。其中「实拍观感」候选刻意模拟写实画面，**并非真实拍摄素材**，也不代表真实素材库授权。
- **口播**：由 macOS 系统 TTS（中文音色 Tingting）生成的自制示例音频，`public/audio/narration.wav/.m4a`；可用 `scripts/build_narration.sh` 重建。
- **生成结果**：预制程序动画，不是在线 AI 输出；界面与文档均明确标注。
- **演示视频**：由 Playwright 对本生产构建进行自动操作录屏，加入操作光标、步骤字幕与系统 TTS 旁白；不是人工录制的真人操作，也不是产品功能本身。
- **许可**：演示资源仅用于本笔试 Demo，不构成任何商业授权。演示素材的“许可说明”弹窗如实说明来源为自制，不伪造授权。

只覆盖「风吹树冠」4 秒示例。输入超出此范围时，界面会提示预制范围，不会伪装成任意需求都得到真实处理。

## 数据与交互边界

- 时长固定 4.0 秒，画幅 16:9，项目总长 15 秒；没有完整时间轴编辑、全片扫描或自动成片。
- 素材库候选固定 3 条；生成示例固定 2 个版本（V1 强风、V2 微风）。
- 失败状态通过独立的「演示控制」开关触发，不在主流程随机失败。
- 不展示匹配分数、真实生成时长、成本或未验证的节省时间数据。
- 不提供真实上传、模型选择、登录或付费能力。

## 验证

在本地起 `npm run dev -- --port 5173` 与 `npm run preview -- --port 4173` 后：

```bash
node scripts/functional_check.mjs   # 核心流程自动化断言，含音频与撤销/替换/失败重试
node scripts/visual_check.mjs       # 全流程截图
```

已核验：无登录打开、跳过解析后继续、两条路径切换不丢需求、上下文预览、插入/撤销/替换、失败保留条件并重试、重置示例；时间线播放推进，口播文件成功加载并在播放/插入时触发。

当前机器的系统输出处于静音状态（`output muted: true`），因此未在此环境完成听感确认；口播轨道在时间线上连续，音频时长为 15.07 秒，建议在有声环境复核音频。验证在 Chrome（Playwright）中完成，未做用户访谈或效果测量。
